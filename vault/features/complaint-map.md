# Complaint map

A chart on the Overview. Departments are on one side and complaint types on the other. Bands join them; the width of a band is the number of cases, and counts are labelled. Selecting a department, a type or a band highlights it and filters the Queue. It reuses the drawing code of the Pipeline view. No source was read on this chart type: our reasoning.

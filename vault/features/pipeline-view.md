# Pipeline view

The complaint process drawn as a flow diagram. Stages are nodes. Paths are bands whose width is the number of cases, with the count on each. It shows the normal path, the fast path for urgent cases, and the loop for cases a specialist returned. A case returned twice takes a different path, to the team lead. Selecting a stage or path filters the Queue. The diagram is drawn from a configuration file. No source was read on this chart type: our reasoning.

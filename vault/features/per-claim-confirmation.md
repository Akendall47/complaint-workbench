# Per-claim confirmation

Each claim in the AI draft is confirmed, edited or removed on its own. Approve stays locked until all are dealt with. An unsupported claim cannot be confirmed. A claim the handler rewrites is relabelled "written by handler" and needs no citation; the edit is logged with the original text and counts as checking. The supporting study did not test this exact control (abstract only, UNVERIFIED). A browser test checks the lock.

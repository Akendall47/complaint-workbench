# Bars, not pies

NN/g: people "are quite adept at estimating how lengths compare"; pie and donut charts "should be avoided most of the time" (read in full). The product uses bars wherever a value must be read accurately, with values labelled directly. Not verified, so not claimed: Cleveland and McGill 1984 full text, Stephen Few's dashboard pitfalls, Tufte's data-ink.

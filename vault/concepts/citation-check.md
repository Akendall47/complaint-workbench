# Citation check

Each claim in the AI draft quotes a passage from the case notes. Plain code checks that the quote appears word for word in the notes. A claim that fails is marked "unsupported" and cannot be confirmed. It is a hard check, not a model's opinion. Research note 03 calls quote-then-answer with a verbatim check standard practice but found no source, so this is our reasoning.

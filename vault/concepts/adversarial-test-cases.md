# Adversarial test cases

A handful of the synthetic cases are adversarial on purpose: complaint text containing hidden instructions, and notes with details that should be masked in unusual formats. They are in the test set. Unsupported claims that appear in the demo are the control working, not a defect to hide. Research note 02 lists injection test cases as a control. The choice of cases is ours.

# Server-rendered fragments

The server returns HTML and the page swaps in small fragments. htmx describes this as server-returned HTML with declarative attributes (read in full). The design uses no build step, no front-end framework and no external requests from the browser. Charts are server-rendered inline SVG with values labelled directly.

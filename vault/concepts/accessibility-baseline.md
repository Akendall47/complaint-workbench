# Accessibility baseline

WCAG 2.2 pages read in full: pointer targets at least 24 by 24 CSS px; text contrast at least 4.5:1, large text at least 3:1; colour never the only signal. GOV.UK error summary, read in full: at the top of the main content, links to each field, wording matches inline messages. The design fixes WCAG 2.2 AA and full keyboard operation as rules regardless of styling. Keyboard-only operation is covered by a browser test.

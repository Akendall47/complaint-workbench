# Vulnerable customers

UNVERIFIED (not researched): FCA guidance FG21/1 names four vulnerability drivers: health, life events, resilience and capability. Handlers should spot signals, record them and adjust handling. In the prototype, possible vulnerability is a claim the model infers rather than reads, so it carries a "check this" flag. Signs of a vulnerable customer are one of the stated rules for the urgent flag. The handover fields include a vulnerability flag and adjustments.

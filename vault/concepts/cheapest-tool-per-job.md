# Cheapest tool per job

Use the cheapest tool that does each job well. Plain code and a small classifier sort and search. A language model only drafts. This is the central argument of the submission. Research note 04 reports that agents use about 4x the tokens of chat and multi-agent systems about 15x (Anthropic, marked confirmed). Applying that to the product's design is our reasoning.

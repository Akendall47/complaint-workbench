# Heatmap caveat

The evidence is against us here. NN/g says "color should not be used to communicate information about quantitative values or magnitude". The owner's reference design uses a heatmap. Research note 07 records the decision: keep one heatmap for the weekday-by-hour arrival pattern, where the shape matters and not exact values; print the count in each cell or on hover and focus; use bars wherever a value must be read accurately. UNVERIFIED: the note does not name the page this quote comes from.

# Band flow diagram

A diagram of nodes joined by bands. The width of a band is the number of cases, and the count is labelled on it. The Pipeline view uses it for stages and paths. The complaint map reuses the same drawing code for departments and types. A free-floating network graph was considered and not chosen: it looks striking but values are hard to read from it. No source was read on this chart type: our reasoning.

**Where it comes from:** the design document. The general chart evidence is in [[07-ux-evidence]], which does not cover this chart type.

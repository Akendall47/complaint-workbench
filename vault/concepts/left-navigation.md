# Left navigation

NN/g: vertical navigation "supports more efficient scanning than horizontal navigation" and suits navigation "likely to grow" (read in full). The cost, from the same article: a "lower content-to-chrome ratio than horizontal navigation". We accept the cost because the product has seven sections and the Case view can collapse the navigation. Research note 07 counted seven; the Pipeline view was added later.

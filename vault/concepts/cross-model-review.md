# Cross-model review

One model reviews another model's work. A June 2026 preprint (not peer reviewed) tested 154 issues across 8 models from 5 providers: no single model exceeded about 64% recall, and 56.5% of defects were caught by only one model. Greptile, a vendor, reports that Codex and Claude each found more bugs in the other's code than in their own. In this build Claude and Codex review each other, and the log records which model caught each defect.

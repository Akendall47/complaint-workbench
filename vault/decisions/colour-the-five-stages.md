# One colour per stage, everywhere

**Decision:** The five case stages keep one colour wherever they appear: New blue, In review indigo, Handed over teal, Returned amber, Accepted green. Chips, bars and the case flow use the same colours, always next to the stage name.

**Who decided:** Owner, 11 Nov: "ensure the stages in the stage table are coloured, eg accepted is green". Which colours: my call. Warm red stays for past deadline and urgent only.

**Why:** a colour learned once reads at a glance on every page. The name stays beside it, so colour is never the only cue ([[colour-not-alone]]).

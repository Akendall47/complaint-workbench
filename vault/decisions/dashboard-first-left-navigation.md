# Dashboard first, left navigation

**Decision:** The product opens on a dashboard and uses left-side navigation with one job per view.

**Who decided:** Owner. Keeping navigation on the left when the first reference image uses top tabs: my call, from the owner's earlier request.

**Why:** The owner did not want one screen doing everything. A team lead gets a morning check; a handler gets a queue.

**Evidence:** [[glanceable-dashboard]] and [[left-navigation]], both from sources read in full ([[07-ux-evidence]]). Not verified: Shneiderman's "overview first" (from memory).

**Trade-off:** Left navigation has a lower content-to-chrome ratio. The Case view can collapse it.

**What would change it:** Our reasoning: far fewer sections.
